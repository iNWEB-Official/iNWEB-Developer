# iNWEB Developer

**iNWEB Developer** হলো iNWEB-এর প্রকাশ্য টিম ওয়েবসাইট। এখানে আমাদের বিভিন্ন পেশাগত ভূমিকা, কাজের ক্ষেত্র এবং টিম পরিচিতি পাওয়া যায়।

**iNWEB Developer** is the public website of the iNWEB team, presenting its professional roles, areas of work, and team profiles.

🌐 **ওয়েবসাইট / Website:** [inweb-official.github.io/iNWEB-Developer](https://inweb-official.github.io/iNWEB-Developer/)

## বৈশিষ্ট্য / Highlights

- বাংলা ও ইংরেজি ভাষার সুবিধা / Bengali and English language support
- বিভিন্ন পেশাগত ভূমিকার পরিচিতি / Profiles for different professional roles
- মোবাইল ও ডেস্কটপে ব্যবহার উপযোগী ডিজাইন / Responsive design for mobile and desktop
- ভূমিকা খোঁজা ও বিভাগ অনুযায়ী বাছাই / Role search and discipline filters
